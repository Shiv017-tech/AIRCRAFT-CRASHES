Aircraft Crashes Analysis

Exploratory data analysis and visualization of airplane crashes and fatalities worldwide since 1908, built with Python.

Figure 1

📌 Overview

This project analyzes historical aircraft crash records to uncover trends in accidents and fatalities over time. The analysis script loads the dataset, processes it, and generates a visualization saved as Figure_1.png.

📂 Repository Structure
File	Description
Airplane_Crashes_and_Fatalities_Since_1908.csv	Raw dataset of aircraft crashes and fatalities
a027.py	Python script for analysis and visualization
Figure_1.png	Output figure generated by the script
📊 Dataset

The dataset contains records of airplane crashes from 1908 onwards. Typical columns include:

Date / Time: when the crash occurred
Location: where the crash took place
Operator: airline or organization operating the aircraft
Flight #, Route, Type: flight and aircraft details
Aboard / Fatalities / Ground: number of people aboard, killed, and killed on the ground
Summary: a short description of the event

Source: The data is widely available on Kaggle. Please refer to the original source for licensing and usage terms.

🛠️ Requirements
Python 3.8+
pandas
matplotlib

Install the dependencies with:

bash
pip install pandas matplotlib
🚀 Usage
Clone the repository:
bash
   git clone https://github.com/Shiv017-tech/AIRCRAFT-CRASHES.git
   cd AIRCRAFT-CRASHES
Make sure the CSV file is in the same folder as the script.
Run the script:
bash
   python a027.py
The figure will be displayed and/or saved as Figure_1.png.
